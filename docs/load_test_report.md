## 4. 総合評価と結論

1. **2048 OID 大規模 MIB 反映性能**:
   - 単一エージェントから 2048 OID を一括取得し、内部状態リポジトリ (`stateRepo`) へ **100% 欠損なく** 反映できることを確認しました。
   - 反映所要時間は約 **35〜40ms** であり、CEL 式による状態評価もサブミリ秒（< 0.05ms）で完了するため、大規模ネットワーク機器のポーリング監視でもボトルネックになりません。

2. **12 Agent 並行シナリオ実行の安定性**:
   - 12 台のエージェント（合計 3,072 OIDs）に対して一斉にシナリオ（Bulk-Get → SET → Inform ACK）を実行した際、**全ジョブが約 45〜50ms 以内に 100% 成功（エラー 0 件）** しました。
   - Apple M2 (16GB RAM) 環境において、CPU 使用率は軽微であり、メモリ消費量も Heap In-Use で 50MB 未満と、16GB RAM の 0.3% 未満に収まっています。

3. **結論**:
   - Musubi は大規模 MIB テーブル（2048 OID 超）および多拠点・多エージェント（12+ 並列）の同時高負荷シナリオにおいても、極めて高いスループットと低レイテンシで安定稼働することが実証されました。
